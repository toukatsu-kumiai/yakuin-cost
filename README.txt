役員行動費かんたん入力（役員専用・ローカル保存PWA）

【主な機能】
・Android / iPhone 共通
・役員行動費の入力、修正、削除、20日締め確定
・確定後も修正可能（修正後はPDFを再作成）
・A4縦の役員行動費請求書兼日別明細書PDF
・設定した理事長名・経理部長名をPDFへ表示
・各役員のバックアップJSONを読み込み、20日締めの全役員集計表をA4横PDFで作成
・入力データは各端末内だけに保存

【全役員集計表の作り方】
1. 各役員が「設定」→「バックアップを書き出す」でJSONを保存
2. JSONを集計担当者へメール等で送る
3. 集計担当者のアプリで「締め・送信」→「役員バックアップを追加読み込み」
4. 全員分を読み込んで「全役員集計表PDFをダウンロード」

【設置】
PWAとしてホーム画面へ追加するには、HTTPS対応のWeb領域へこのフォルダ一式をアップロードしてください。入力内容はサーバーへ送信されません。

【印刷】
・個人明細：A4縦
・全役員集計表：A4横
印刷時は倍率100%または「実際のサイズ」を選択してください。

【今回の追加】
主な実施内容は候補リストから選択でき、候補にない内容は自由入力できます。
